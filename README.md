# AquaPlan – Farm Weather & Irrigation Planner
Single-page web app (vanilla JS) that recommends when and how much to irrigate.
APIs: Open-Meteo, MockAPI.io.

Team: Ravy Lang, Kithya Tes, Menghong Ing, Sivhuy Hong, Hak Sokhai
Course: INFO 251 001 – Web Development II, AUPP

## Run locally
From the project folder, start a local server and open the printed address:
    npx serve .
(or: python -m http.server 5500 → http://localhost:5500)
